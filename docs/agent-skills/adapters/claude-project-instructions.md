# GraveOps Project Instructions

The repository-root `AGENTS.md` is canonical. Read it first, then use `skills/graveops-engineering-router/SKILL.md` to select the smallest sufficient specialist workflow.

For bugs, reproduce and diagnose before editing. For features, use test-first development at stable seams. For all non-trivial changes, run cross-platform architecture and code-review gates. For privileged, destructive, package, updater, or release work, use the safe-change/release skill.
